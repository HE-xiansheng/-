ros2-livox将enP3p49s0设为192.168.1.51/32，仅添加192.168.1.158/32直连路由。这样不创建覆盖WiFi管理网的192.168.1.0/24路由；是旧机“删除/24、保留/32”意图的候选等价实现，临时等效配置已完成真实原生60秒33/33检查。启动真实Livox驱动后设备的数据目标使用新机.51；新机收到实物点云/IMU才算通过。

ros2-gimbal为已观察到的USB网卡绑定192.168.144.100/24，与旧机相同。若使用另一块网卡，应重新读取实际接口/MAC并修改候选，不能凭相似名称激活。

Livox候选autoconnect=true、priority100、绑定板载MAC；云台候选autoconnect=false。两份均never-default=true、无gateway/DNS、IPv6 disabled；激活只改变所选传感器有线接口。不要复制文件到系统路径或执行nmcli load/import/up，直到完成接线/地址占用核查、保存实际连接快照，并由用户确认网络切换影响。libnm解析通过不等于地址无冲突、路由可达或驱动实测通过。

## 激活后的实际验收与回退准备

先明确物理接线、对应MAC与.51/.100地址唯一性，保存现有nmcli连接和ip地址/路由快照。经确认后以root:root/0600安装候选、由NetworkManager加载后逐个激活，不改WiFi；检查SSH仍在线、默认路由仍经wlan0、雷达.158精确路由源为.51、云台.144.108走USB网卡。之后依次读取实际雷达/IMU、真实定位、只读飞控接收状态、云台RTSP及MPP数据，并取回证据。

需要回退时先停止本次所属候选进程，停用/移除这两个专用连接并恢复前述快照中的原连接；所有实际连接启停仍需遵守用户对正式环境变更的确认要求。持久候选未激活；临时内存测试连接已删除并恢复原DHCP，因此目前无测试网络修改需要撤销。.235始终只读。
