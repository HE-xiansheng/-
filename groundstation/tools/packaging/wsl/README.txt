科研飞行平台：Windows11 WSL一键安装包
运行版本：1.0.20261111.1　安装脚本：2026.11.11.1

使用方法
1. 将整个ZIP完整解压到一个文件夹，不要在压缩软件里直接运行。
2. 双击“一键安装.cmd”，允许Windows弹出的管理员授权。
3. 完成后双击Windows桌面“科研飞行平台-地面站（WSL）”。
4. 使用密码认证时，每次打开地面站后，在“机载通信”输入机载电脑密码，点击“应用并连接”，再使用定位、任务和视频。已有可用SSH密钥时可以留空。

系统与联网
适用Windows11 22H2及以上x64电脑，使用WSL2、Ubuntu20.04及WSLg图形支持。
包内包含微软官方WSL3.0.5 x64 MSI、Ubuntu官方20.04.6镜像和Linux地面站安装文件；Ubuntu软件依赖及部分Windows组件仍可能需要联网。
仅系统明确报告需要重启Windows时才提示，自行保存工作并重启，然后再次运行同一安装器继续。脚本不会自动重启Windows。
镜像网络发生变化时会重启WSL，其中其他程序也会退出，请提前保存工作。

从旧版升级
升级前关闭旧安装版地面站窗口，再运行新版“一键安装.cmd”。
旧程序、日志和用户数据保留；新版必要时装入独立版本目录，并更新Windows桌面入口。
安装器只回收旧安装目录自己管理的本地只读遥测后台，不停止机载定位、规划或飞控服务。
无需先卸载WSL、删除Ubuntu或清理下载缓存。

一键卸载
安装完成后开始菜单也有“卸载科研飞行平台-地面站（WSL）”，删除解压目录后仍能使用。
先关闭地面站窗口，再双击同目录“一键卸载.cmd”，允许专用防火墙规则清理的管理员授权。
卸载地面站及其快捷方式、专用规则，安装目录内新增文件先备份；保留WSL、Ubuntu、用户配置、SSH凭据、飞行数据和日志。
详见“卸载说明.txt”；独立卸载包也兼容旧版，无需先升级。

卸载入口修复：避免导入安装脚本时FunctionsOnly参数覆盖导致直接退出；卸载入口在导入依赖之前记录日志，CMD另写启动日志及退出码。

本版包含的修复
- Ubuntu从包内镜像导入，避开发行版清单下载超时。
- 修复原生WSL参数引号和输出编码，保留此前安装脚本修复。
- Windows与Hyper-V防火墙规则使用不同名称，只处理本工具规则，不关闭防火墙。
- Ubuntu依赖下载失败有限重试，保留有效下载缓存。
- WSL内部状态和栅格UDP走Linux lo，发送错误限频记录。
- 后台SSH采用固定密码助手，避免GUI退出后临时助手被删除导致重连失败。
- 启动时读取保存的机载地址，并统一视频和通信地址，支持显式--host覆盖。
- 云台RTSP仅对当前机载中继地址绕过代理，保留其他代理配置。
- 升级校验主程序、通信助手及视频包装器，防止误复用旧脚本或丢失执行权限。

认证与数据
密码仅用于本次会话，不写入安装包、脚本、配置或日志。后台遥测仍有数据，不代表新开的前台会话已重新认证。
SSH主机指纹校验保留。安装过程不登录机载电脑或启动飞行任务。
没有点云时查看ROS话题栏和FAST-LIO状态；机载没有发布点云时，地面站会等待数据源。
安装包包含必要通信助手，不附完整C++/QML工程源码、SSH私钥、现场密码或录包。

四份通信及两份视频修复脚本来自用户Windows/WSL实机验证结果，用户已确认话题栏、重连及两路视频恢复。
合入时另补齐正式主程序的--host读取及统一地址初始化，避免启动脚本参数被忽略；这部分需随新版完整包现场复测。
本次重新打包通过本地隔离通信、升级校验及Linux实际安装/界面首帧/卸载检查；新版完整包的Windows首次安装和升级仍需现场复测。
